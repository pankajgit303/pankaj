# Islampur PujoParikrama

A responsive Durga Puja pandal directory and interactive guide for Islampur, Uttar Dinajpur, West Bengal 733202.

**Created by**: [Pankaj Singha](https://pankajportfolioo.vercel.app/)

## Features
- **Home**: Overview with 27 verified pandals & temples, live search, and area filter
- **Map**: Interactive full-town Leaflet map with custom markers, GPS live location, and directions
- **Near Me**: Real-time proximity radar with walking and toto travel times
- **Route**: Multi-stop itinerary builder with curated trails and Google Maps navigation export

## Run Locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.

## Deploying to Vercel
This repository includes a `vercel.json` file configured for instant zero-error static hosting:
1. Push this repository to GitHub.
2. In Vercel, click **Add New → Project** and import this repository.
3. Keep the default settings (Framework: **Other**, Root Directory: `./`).
4. Click **Deploy**. Vercel will automatically serve all static files (`index.html`, `style.css`, `script.js`).
