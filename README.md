# Islampur Pujo Hoppers

A responsive static website concept inspired by pandal-hopping guides, tailored for Islampur, Uttar Dinajpur, West Bengal 733202.

## Files
- `index.html` — page structure and 27 local community puja committee and Durga temple listings
- `style.css` — responsive styling
- `script.js` — search and neighbourhood filter

## Run locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Deploy to Vercel
1. Create a GitHub repository and upload these three files (plus this README).
2. In Vercel, choose **Add New → Project** and import the repository.
3. For a static site, leave the framework preset as **Other** and leave the build command empty.
4. Deploy.

## Important
The 27 listed places combine community puja committees and Durga temples gathered as starting points; they are not a guaranteed exhaustive directory and are not verified live 2026 schedules. Confirm locations, timings, committee permissions, and current arrangements before publishing as definitive information. Replace the CSS-generated illustration cards with approved local photos when available.
